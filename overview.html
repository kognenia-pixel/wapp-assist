1. Contexte et vision

Fondateur : Moussa Moise Agnessan. Structure : Kognen IA, puis agence Routine, basee a Conakry (Guinee).

Vision : vendre des services d automatisation IA aux PME guineennes, sans abonnement, sans dependance a des plateformes etrangeres, en gardant 100 % des benefices.

Produit phare — Wapp Assist : un assistant WhatsApp IA qui repond aux clients 24h/24 avec leurs produits, leurs prix, leurs horaires. Installe une fois, pas de commission, heberge sur le compte Cloudflare du client.

Public cible : restaurants, pharmacies, boutiques, agences immobilieres, commerces recevant des demandes WhatsApp hors horaires d ouverture.

3. Fonctionnalites principales

3.1 Cerveau IA (Worker)

  • Reception des messages WhatsApp via webhook Meta, reponse via Gemini (modeles flash-lite / flash / pro avec fallback).
  • Carnets /admin/kb : produits, FAQ, horaires. Instruction anti-hallucination : si info absente, repondre « Je verifie avec l equipe ».
  • RAG /admin/sources : ingestion PDF / TXT / URL, embeddings text-embedding-004 (fallback gemini-embedding-001), seuil 0.3.
  • Historique par conversation, proactivite configurable (delai, relance sur « ? »).

3.2 Interface de gestion (web-ui)

  • Dashboard : statut Worker, compteurs produits / FAQ / sources, conseil du jour.
  • Meta : URL Worker, ADMIN_SECRET, Phone Number ID, test de connexion.
  • Produits : CRUD nom / prix / description.
  • FAQ et Horaires : CRUD questions / reponses + horaires.
  • Sources : ajout PDF / TXT / URL, indexation RAG, score de pertinence.
  • Assistant : Apparence (couleur, icone, bulle, fond), Personnalite (ton, registre, style, instructions systeme), Connaissances, Comportement (longueur, proactivite, delai, historique).
  • Progression : gamification (badges, niveaux, barre), onboarding et tutoriel en 6 etapes.

4. Installateur web — zero terminal

Formulaire en 6 etapes visuelles avec barre de progression, logs SSE en direct dans une console moderne (fond sombre, texte vert, scroll), mode simulation sans SSH.

  1. Serveur SSH : IP / domaine, port 22, utilisateur, mot de passe ou cle PEM, dossier distant, INSTALLER_SECRET.
  2. WhatsApp en 1 clic : bouton « Connecter avec Meta » (popup 600x700, polling /auth/status), fallback manuel token + Phone Number ID.
  3. Cloud : Cle Gemini, Cloudflare Account ID + API Token.
  4. Secrets : ADMIN_SECRET + VERIFY_TOKEN inventes par le client.
  5. Marque blanche : nom, couleur, numero public, URL logo (optionnel).
  6. Lancement : bouton Installer, progression 1/6 a 6/6, URL Worker affichee, bouton fallback « Generer commande ».
Securite : secrets gardes en memoire le temps du job (Map, GC 30 min), masques par *** dans les logs, header X-Installer-Secret, timeout 20 min, HTTPS en production.

Endpoints : POST /api/install, GET /api/install/:jobId/stream (SSE), GET /api/health, POST /api/verify-license, GET /auth/meta, GET /auth/meta/callback, GET /auth/status.
