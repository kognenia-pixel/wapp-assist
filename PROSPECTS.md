# Prospects priorisés — Wapp Assist

## 1. Restaurants (priorité #1 — ta démo est un resto)
- Pourquoi : fort volume WhatsApp, menu/prix/horaires = cas parfait.
- Cibles Conakry : Yaya Grill, Primus, restaurants Kaloum/Minière, traiteurs WhatsApp.
- Angle : “Vos clients commandent à 21h, vous dormez. Wapp répond à votre place.”
- Canal : visite 15h-17h (creux), démo sur ton tel en 30s.

## 2. Pharmacies (test validé)
- Pourquoi : horaires, stock, livraison → questions répétitives.
- Cibles : pharmacies ouvertes 24/24, groupes WhatsApp “Pharma Guinée”.
- Angle : “Ne perdez plus un appel ‘Vous avez X ?’ la nuit.”

## 3. Boutiques en ligne / vendeurs WhatsApp
- Pourquoi : déjà sur WhatsApp Business, catalogue = leur vie.
- Cibles : vendeuses Instagram→WhatsApp (mode, cosmétiques, téléphones), Jumia sellers.
- Angle : “1 000 000 une fois vs un community manager chaque mois.”

## 4. Freelances / agences (effet levier)
- Pourquoi : ils revendent à leurs clients (resto, boutique) → 1 vente = N installations.
- Cibles : créa Conakry, dev no-code, agences “site vitrine”.
- Angle : “Produit blanc à revendre — tu factures l’install 2M, tu gardes la marge.”
- Offre : licence libre → ils peuvent installer pour leurs clients sans te repayer.
